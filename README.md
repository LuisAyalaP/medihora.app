# Sitio de MediHora

- `index.html` — página de inicio
- `privacidad.html` — aviso de privacidad
- `support.js` — runtime de las páginas (debe quedar junto a los .html)
- `assets/` — capturas, icono, insignia de Google Play y video

Para GitHub Pages: sube el contenido de esta carpeta a la raíz del repo y activa Pages desde la rama principal.
